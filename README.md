# SELENE · VIVEK

> **Watch the Earth rise.** A cinematic concept for lunar expeditions, featuring frame-by-frame parallax storytelling, cosmic dust shaders, an animated cislunar trajectory tracker, and mission manifests.

---

## 🌒 Overview

**SELENE · VIVEK** is an interactive, motion-driven web experience capturing the human voyage beyond Earth orbit. As you scroll, the experience transitions from a drifting cosmic dust veil to the rising Earth above the lunar horizon, followed by mission reels, trajectory flight legs, and expedition bookings.

### Key Highlights
- **Multi-layer Cinematic Parallax**: 6 synchronized photographic layers responding dynamically to scroll progress.
- **Particle Dust Shader**: HTML5 Canvas rendering of cosmic micromotes clearing on scroll.
- **Scroll-Linked Trajectory Flight Path**: Vector-rendered orbital maneuvers from Earth orbit insertion to terminal touchdown.
- **Horizontal Mission Reel**: Smooth horizontal log tracking mission milestones.
- **Responsive Architecture**: High-resolution desktop and mobile asset pipelines with full reduced-motion accommodations.

## 🛠️ Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm

### Installation & Run

1. Clone the repository:
   ```bash
   git clone https://github.com/vivekdandotiya/demo2.git
   cd demo2
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
